# Cumulative Stack Reel

A one-take, roughly 25-second reel built from a single sentence that grows. Each line
repeats every element said so far, adds one new one, and promises a bigger result. The
repetition is the hook: viewers feel the list getting heavier and stay to hear the last line.

Source: Talha (@talhacoachauthority), reel DeXgkv_M7t_. His version:

> If you share a generic story, your audience will ignore you.
> But if you share a story **and your past**, they'll become curious.
> …story, past **and your achievement** → they'll pay attention.
> …story, past, achievement **and the steps** → they'll be invested.
> …story, past, achievement, steps **and all your learnings** → they'll become die-hard fans.

## Anatomy

```
Rung 1: If you [A],                      [weak result].
Rung 2: But if you [A] and [B],          [better result].
Rung 3: But if you [A], [B] and [C],     [better still].
Rung 4: But if you [A], [B], [C] and [D], [strong result].
Rung 5: But if you [A]…[D] and [E],      [the payoff].
```

## Rules

1. **4–6 rungs.** Fewer doesn't build momentum. More turns the repetition into a chore.
2. **Rung 1 is what most people already do.** The baseline should be instantly
   recognizable, and its result should sting a little ("they'll ignore you", "you'll quit by
   Wednesday").
3. **Each element is 2–5 words.** Every element gets said again on later rungs, so long ones
   make the reel drag. Name each element as a noun or a short verb phrase: "your past", "the
   steps", "track it".
4. **The elements must really compound.** Each one has to depend on or build on the ones
   before it. If the order could be shuffled without anyone noticing, it's a list, not a
   stack, and this format is the wrong one.
5. **The results climb on one scale.** Pick one thing to measure (attention, trust, results,
   money) and move it up a step on every rung. Don't jump from "they'll like it" to "you'll
   make $10k".
6. **Keep the repetition word for word.** The same element should use the same words on
   every rung. Changing the wording breaks the rhythm. Compressing is allowed on the last
   rung only ("…and the steps, and then share everything you learned").
7. **The last element is the one you own.** Make the final rung the piece your offer
   provides (accountability, the system, the coaching), so the payoff points at what you do
   without a pitch.
8. **CTA is optional and short.** The original has none: it ends on the payoff and loops.
   If you add one, keep it to a single line after the final rung, such as a comment trigger
   word tied to the last element.

## Workflow

1. Get the **framework** (the 4–6 compounding elements) and the **result scale** from the
   user's topic. If they give a brain dump, pull the elements out of it and confirm the
   order before writing.
2. Write a results ladder first, as just the reactions in rising order. Check that it climbs
   on one scale.
3. Write the rungs. Read them out loud in your head: the last rung should take 6–10 seconds
   to say, and no longer.
4. Add on-screen text that stacks: each new element appears under the previous ones and
   stays there, so the screen builds into the full framework by the end. It ends as a
   saveable checklist.

## Variants

- **Negative stack:** "If you skip A, … But if you skip A and B, …" with the results getting
  worse. Works for warnings and pattern-awareness content.
- **Audience stack:** the same elements, with the results naming who you attract at each
  level ("strangers → followers → fans → clients").
- **Reverse reveal:** open on the final payoff ("Here's how you turn followers into
  clients"), then run the stack.

## Output format

```
### <working title>
**Framework:** A → B → C → D → E
**Results ladder:** <r1> → <r2> → <r3> → <r4> → <r5>

**Script (~<N> words, ~<N> sec):**
If you <A>, <r1>.
But if you <A> and <B>, <r2>.
…
<optional one-line CTA>

**On-screen text (stacks as you go):**
1. <A>
2. <B>
…
**Caption:** <1–2 sentences + the framework as a list>
**Alt hooks:** <2 options: reverse reveal, or a negative-stack first line>
```

Write it to be spoken in one fast, steady take, first person, with no filler between rungs.
